Safe 操作 SOP 推荐：离线签名

建议按顺序执行；遇到问题见文末“常见问题 & 安全清单”。

一、准备

  1. 安装并解锁浏览器钱包（MetaMask / Rabby 等）。
  2. 在本页 连接钱包 → 选择网络（ETH/Arbitrum/BNB 等）→ 绑定 Safe 合约。
  3. 点击 读取 threshold / nonce，确认 阈值 与 nonce。

二、填写并确认交易参数

  1. 填写收款地址、金额、data 等；先后点击“确认地址 / 确认金额”锁定。
  2. 点击 计算 safeTxHash；如需多人操作，使用“共享/二维码/文件”把参数分发。

三、离线签名模式（推荐）

  1. 在“签名模式”选择 离线签名（EIP-712）。
  2. 每位 Owner：点击 我来签（或粘贴签名），面板会验签 + 去重。
  3. 收集到 ≥ 阈值后，点击 执行（execTransaction），核对二次确认弹窗与钱包内容一致 → 签名 → 等回执。

四、在线批准模式（approveHash 上链）

  1. 在“签名模式”选择 在线批准。
  2. 每位 Owner 点击 approveHash 并上链；随后点 刷新批准状态 查看 ✅ 列表。
  3. 当达到阈值，点 根据批准状态生成 signatures → 执行 → 等回执。

五、取消/作废当前交易（同 nonce）

  1. 点击 准备取消交易（同 nonce 的空交易），系统会填充：to=Safe、自身、value=0、data=0x。
  2. 离线模式：收集取消交易的离线签名到阈值后执行；在线模式：Owner 们对新 hash 执行 approveHash，达阈值后执行。
  3. 注意 谁先执行，谁吃掉 nonce；原交易自然失效。建议提高手续费优先级以确保取消优先上链。

六、共享与导入

  1. 点击 生成分享字符串 或 显示二维码 或 下载 JSON；内容自带 SHA-256 指纹。
  2. 第二人打开链接（或粘贴字符串/导入文件）→ 页面会自动填充并本地重算 safeTxHash 校验一致性。
  3. 导入后建议点击 刷新批准状态，以链上结果为准。

七、常见问题 & 安全清单

  1. 核对 二次确认弹窗与钱包弹窗：网络、Safe、收款地址、金额、data 字节数、nonce、safeTxHash。
  2. 密钥安全 本工具不会收集私钥/助记词；如任何页面要求填写助记词，立即关闭。
  3. 阈值不足 离线签名未达阈值或链上批准不足时，执行会被拒；先补齐再执行。
  4. 网络不匹配 钱包网络与页面显示不一致时，先切链；金额单位会随链自动切换。
  5. 取消交易 无法“撤回 approve”；使用“取消交易”同 nonce 吃掉当前 nonce。
  6. 分享安全 仅把参数/哈希分享给可信对象；离线签名只在临门时转交，避免被他人代执行。
